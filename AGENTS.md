# Telegram Materialization

Standalone Three.js effects extracted from androman.pro. Keep WordPress out of this repository. Public assets are self-hosted. Preserve Three.js MIT and font OFL licenses.

Maintain RU and EN UI, scene inscriptions and documentation together. Recording tools must use this isolated stand on loopback. Store raw capture frames and audit logs outside the repository. Run Node geometry/physics tests and browser checks before publishing. Commits use explicit reviewed paths and contain no tool coauthor trailers.
